# Revolutionizing Digital Learning With AI
### Technology Used
* **Frontend:** React, tailwind CSS  
* **Backend:** Node.js, Express, & MongoDB  
* **AI:** Gemini API, ImageKit API
## Project Structure
* `frontend`: Contain the frontend code built with React & tailwind CSS
* `backend`: Contain the backend code with Node.js & Express
## Installation
### Prequisities
* Node.js & npm installed on your system
* MongoDB installed & running
### Steps

1. **Clone the Repository**
    
   ```bash
   git clone  
   cd FYP
   ```
   
2. **Install Dependencies for backend**
     
   ``` bash
   cd backend
   npm install
   ```
   
3. **Install Dependencies for frontend**
     
   ```bash  
   cd frontend
   npm install
   ```
   
4. **set up environment variable for backend**

   - create a `.env` file in the `backend` directory and add the following:

     ```text
      Mongo
     ```

5. **Run the backend**

   ```bash
     cd backend
     npm run dev
   ```

6. **Run the frontend**

   ```bash
     cd frontend
     npm run dev
   ```
